# Flashcard Project

Thư mục này chứa project HTML cho ứng dụng flashcard học lý thuyết, được chia thành 3 trang riêng:

- create.html: tạo bộ flashcard
- library.html: chọn bộ flashcard
- study.html: học flashcard

## Cách mở
Mở bất kỳ file HTML nào trong thư mục bằng trình duyệt để xem giao diện.

## Mục tiêu sớm
- Tạo giao diện cơ bản
- Chọn và học flashcard
- Điều hướng giữa các màn hình dễ dàng
